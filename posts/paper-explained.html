01 / The experiment

Same tasks, different order.

I trained a small neural network on five tasks. Each task asked it to distinguish a different pair of handwritten digits. The network learned one task at a time. I tried every possible order and started training from scratch for each repeat.

Total forgetting adds up the difference between each task’s test accuracy right after the network learned it and its test accuracy at the end of training. In this experiment, the order alone changed average forgetting. Smaller values mean the network remembered more.

For specialists Each experiment here uses split-MNIST with an MLP and task-specific output heads.

02 / Geometry

The space of all orders.

For a shape we can rotate on screen, switch to a separate experiment with four tasks. In order B–A–C–D, task A is second, B is first, C is third, and D is fourth. The four slot numbers always add up to the same total, so three coordinates are enough to locate each order. The orders form the corners of a shape called a permutohedron.

Follow an edge and you swap two neighboring tasks. Forgetting is a value at each corner, like elevation on a map. Shade stands in for height here, so you can still see the edges clearly.

For specialists The vertices are the permutations of the four positions projected isometrically into their sum-zero subspace after centering.

03 / Replication

Real or noise?

A random seed controls choices such as the network’s starting weights and the order of its training examples. I used the same set of seeds for every task order. Forgetting varies from seed to seed even when the order stays fixed. Compare entire sets of orders across seeds and a pattern emerges.

The paper counts the differences between orders that repeat across independent seeds. Try averaging more seeds and watch how the landscape settles.

For specialists The signal estimate averages inner products across distinct centered seed landscapes, leaving out within-seed squared terms.

04 / Decomposition

Splitting order into layers.

A sound can be split into frequencies. Each frequency describes a different kind of variation, and adding them back gives the original sound. The paper applies the same idea to forgetting across orders. Its layers describe different kinds of order effects.

Some differences come from where individual tasks sit. Some depend on which two slots a pair occupies, with the same contribution if the tasks trade places. The slots can be far apart. Another layer captures pair effects that change when the two tasks exchange positions. Add the layers in the figure to see how much of the measured shape they recover.

Effects involving more than two tasks account for a measurable share of the repeatable differences in this setting. A model built entirely from positions and pairs can describe much of the landscape. That remainder stays outside its reach regardless of how its parameters are chosen. The paper detects this remainder in both of its main experiments under two assumptions. The seeds are independent, and under the hypothesis that positions and pairs explain the full pattern, each seed’s remaining pattern and its sign-reversed version are equally likely.

For specialists This is a Fourier transform on the symmetric group of task permutations, grouped by isotypic component and assignment degree.

05 / Interpretation

What the layers say about the tasks.

The position layer gives each task a score for each slot. The scores are centered, so a negative value means that particular placement is associated with less forgetting in the position layer. The pair fit asks how much of the layer for pairs in either order can be explained by immediate neighbors.

For specialists The table comes from the degree-one projection. The adjacency fit is applied to the symmetric-pair projection.

06 / Model comparison

What each theory can see.

Every theory about task order can express certain patterns. A model built on “A before B” can express some position effects and some effects of which task comes first. It covers only part of the layer for effects that change when tasks trade places. It cannot express the layer whose pair effects stay the same after a trade. For this experiment, that is the biggest layer.

Choose a model to see its best fit to the average landscape. The matrix shows which patterns a model can express in principle. The score shows how much of the repeatable effect in this experiment falls within its reach.

The flexible symmetric-pair row covers the class used by Li and Hiratani, Lin and colleagues, and Cao, Cheng and Shen. The last two rows fix the position weights to the published Cao–Cheng–Shen choices.

For specialists Model capacity is the rank of the projected feature space within each component. The two-component support of pairwise-order features follows from the Kendall-kernel spectrum in Mania et al. (2018).

07 / Prediction

Can you beat best-of-n?

You can measure a limited number of orders. When your budget runs out, choose any order. Your choice is scored on precomputed runs with seeds that were hidden during play. Your rivals are a fitted “A before B” model and a simple rule: keep the best order you measured.

The simulations use this five-task MNIST example.

For specialists The game fits ridge regression on pairwise-order features and measures normalized regret on held-out seeds.

08 / Takeaways

What it means.

  • Order matters. The same network can remember very different amounts after learning the same tasks.
  • Repeated runs reveal structure. Positions and pairs explain most of the effect in this experiment. Some repeatable differences involve more tasks at once.
  • Explanation and prediction are different tests. A theory can describe a measured landscape well and still choose a worse order than simply keeping the best one it tried.

Where to go next

For theorists
Check which patterns a model’s features can express. The layer breakdown can help you decide which features to add.
For continual-learning researchers
Repeat orders across seeds and report what holds up across runs. These small digit tasks make complete experiments possible. Larger systems need their own measurements.
For practitioners
Keep the best measured order as a baseline. Evaluate any recommendation on fresh runs before acting on it.
